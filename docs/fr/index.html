Senklot

Un caractère variable au centre de gravité mobile. Tirez le poids vers le bas et les lettres s’alourdissent sur la ligne de base. Déplacez-le sur le côté et la graisse suit. Les retours à la ligne ne bougent pas.

Déplacez le pointeur autour du titre, ou faites défiler rapidement pour sentir son inertie.

L’idée

Un chantier. Un fil à plomb à la main. Je l’ai regardé osciller, puis s’arrêter net. Et je me suis dit : et si la typo pouvait faire ça ?

Alors je l’ai construit. Voici Senklot.

La plupart des caractères répartissent leur graisse selon la direction du trait. Senklot donne à chaque lettre un poids que vous pouvez déplacer. Faites-le descendre. Montez-le. Poussez-le sur le côté.

Le squelette ne bouge pas, votre mise en page non plus. Seule l’encre se déplace. Points et trémas suivent comme un lest libre.

Senklot signifie « fil à plomb » en allemand. Deux axes déplacent son poids : BLSY vers le haut ou le bas, BLSX sur le côté.

2styles : romain et une véritable italique
300–800graisse continue, de Light à ExtraBold
2axes de lest pour déplacer le poids verticalement et horizontalement
217glyphes : Europe de l’Ouest, polonais et tchèque, ß et ẞ compris

Les axes se combinent librement. Quinze masters par style décrivent l’interaction entre graisse et lest, si bien qu’un Bold Italic dont la masse est descendue à gauche est dessiné avec autant de soin qu’un Regular au repos.

L’italique

    

      
Senklot Italic est une véritable italique, pas un romain penché. Le squelette est incliné de 9° avant que les traits soient tracés, si bien que chaque trait garde sa vraie épaisseur au lieu d’être écrasé.

      
Plusieurs lettres sont redessinées. Le a passe à un seul étage, le f descend sous la ligne de base et revient en crochet, et les fûts de a d i h m n u se terminent par de petites sorties. Le lest fonctionne toujours : en italique, la masse se rassemble dans ces sorties.

Le texte au repos

    

      
Un caractère de texte polyvalent a deux missions. Il doit s’affirmer dans un titre et s’effacer dans un paragraphe. Au repos, Senklot est une linéale calme et ouverte, avec une hauteur d’x généreuse, des ouvertures larges et des fins de trait coupées presque à l’horizontale ou à la verticale.

      
Sa personnalité tient à une légère attraction vers le bas : les barres sont basses et les fûts s’épaississent un peu vers la ligne de base. Elle est ancrée sans être lourde, et l’italique garde ce même poids tranquille. Ce n’est qu’en déplaçant la masse que le système se révèle.

      
Größe, Übermut und Äpfel : les trémas portent leur propre lest. Les chiffres 0123456789 tiennent le même aplomb.

L’utiliser sur votre site

    
    
      
  1. Copier les fichiers
    Décompressez le téléchargement et copiez le contenu de web/ dans un dossier de votre site, par exemple /fonts/. Ce dossier contient cinq fichiers : senklot.css, les deux fichiers variables .woff2, OFL.txt (licence des fontes) et LICENSE-CODE.txt (licence de la feuille de style). Gardez-les ensemble.
    2. 
      
  2. Lier la feuille de style
    
        
    <link rel="preload" href="/fonts/Senklot[wght,BLSY,BLSX].woff2" as="font" type="font/woff2" crossorigin>
<link rel="stylesheet" href="/fonts/senklot.css">
    3. 
      
  3. L’utiliser comme n’importe quelle fonte
    
        
    body   { font-family: "Senklot", system-ui, sans-serif; }
strong { font-weight: 700; }
em     { font-style: italic; }        /* choisit la véritable italique */
h1     { font-weight: 600; }
    4. 
      
  4. Déplacer le lest
    
        
    La graisse et l’italique passent par le CSS habituel. Les axes de lest passent par font-variation-settings. Cette propriété se remplace en bloc : définissez donc toujours les deux axes ensemble. Les propriétés personnalisées simplifient cela :
    
        
    h1 {
  font-variation-settings: "BLSY" var(--blsy, 0), "BLSX" var(--blsx, 0);
  transition: font-variation-settings .6s cubic-bezier(.3, 1.6, .5, 1);
}
h1:hover { --blsy: 100; }

/* respecter ceux qui désactivent les animations */
@media (prefers-reduced-motion: reduce) {
  h1 { transition: none; }
}
    5. 
      
  5. Animer en JavaScript
    
        
    Ce code pilote les propriétés personnalisées de l’étape 4. Le CSS garde ainsi la main et la réduction des animations est respectée.
    
        
    const el = document.querySelector("h1");
const reduced = matchMedia("(prefers-reduced-motion: reduce)").matches;

if (!reduced) {
  addEventListener("pointermove", e => {
    const y = (e.clientY / innerHeight * 2 - 1) * 100;
    const x = (e.clientX / innerWidth  * 2 - 1) * 100;
    el.style.setProperty("--blsy", y.toFixed(1));
    el.style.setProperty("--blsx", x.toFixed(1));
  }, { passive: true });
}
    6. 
    

    
Compatibilité : les fontes variables à axes personnalisés fonctionnent dans toutes les versions actuelles de Chrome, Edge, Safari et Firefox. Pour les anciens navigateurs ou les environnements sans fontes variables, les fichiers statiques de web/static/ offrent six graisses fixes par style, sans les axes de lest.

Comment il est construit

    

      

        
Chaque glyphe est un squelette de droites et d’arcs de superellipse. Le contour est obtenu en décalant chaque point de ce squelette d’une demi-épaisseur tirée du champ :

        
demi-épaisseur = base × contraste × (1 + 0.10·v + 0.55·BLSY·v + 0.40·BLSX·u)

        
Le contraste allège les traits horizontaux d’environ 12 % par rapport aux verticaux, comme dans la plupart des linéales. Le reste vient du champ : u est la position horizontale depuis le centre de la lettre (−1 à gauche, +1 à droite) et v la hauteur, de +1 au jambage inférieur à environ −0,7 au jambage supérieur. BLSY et BLSX sont les valeurs des axes divisées par 100, donc de −1 à +1. Comme chaque point du contour dépend linéairement de cette demi-épaisseur, les masters sont compatibles par construction. À l’écriture des fontes, les coordonnées sont arrondies à l’unité.

      

      
    
        
  • 15 masters par style, y compris les coins graisse × lest, pour que les combinaisons ne nécessitent aucune correction supplémentaire.
    • 
        
  • Quand la graisse augmente, les bords arrondis sont ramenés vers l’intérieur pour que les débordements restent sur les lignes de référence.
    • 
        
  • L’italique incline le squelette de 9° avant le tracé, si bien que les traits gardent leur épaisseur perpendiculaire.
    • 
        
  • Crénage par classes pour les paires courantes, lettres accentuées comprises.
    • 
        
  • Tous les fichiers passent l’OpenType Sanitizer, le contrôle que les navigateurs appliquent aux fontes web.
