Senklot

Eine variable Schrift mit beweglichem Schwerpunkt. Zieh das Gewicht nach unten, und die Buchstaben werden an der Grundlinie kräftiger. Beweg es zur Seite, und die Strichstärke wandert mit. Die Zeilenumbrüche bleiben dabei gleich.

Bewege den Zeiger um den Titel oder scrolle schnell, um die Trägheit zu spüren.

Schriftfamilie herunterladen Schrift ausprobieren

Die Idee

Baustelle. Ein Senklot in der Hand. Ich sah zu, wie es pendelte und dann stockstill hing. Und ich dachte: Was, wenn Schrift das könnte?

Also habe ich sie gebaut. Das ist Senklot.

Die meisten Schriften verteilen ihr Gewicht nach der Strichrichtung. Senklot gibt jedem Buchstaben ein Gewicht, das du bewegen kannst. Absenken. Anheben. Zur Seite schieben.

Das Skelett bleibt stehen, dein Layout auch. Nur die Tinte wandert. Punkte und Umlaute schwingen mit wie loser Ballast.

Ein Senklot ist das Lot der Bauleute. Zwei Achsen bewegen sein Gewicht: BLSY auf und ab, BLSX zur Seite.

2Stile: aufrecht und eine echte Kursive
300–800stufenloses Gewicht, Light bis ExtraBold
2Ballast-Achsen für senkrechte und waagerechte Gewichtsverlagerung
182Zeichen: Umlaute und ß, œ und æ, ¡ ¿ und Akzentbuchstaben

Die Achsen lassen sich frei kombinieren. Fünfzehn Master pro Stil beschreiben, wie Strichgewicht und Ballast zusammenspielen. So ist Bold Italic mit nach links abgesunkener Masse genauso sorgfältig gezeichnet wie Regular in Ruhe.

Die Kursive

    

      
Senklot Italic ist eine echte Kursive, keine schräg gestellte Aufrechte. Das Skelett wird um 9° geneigt, bevor die Striche gezeichnet werden. So behält jeder Strich seine echte Dicke, statt gestaucht zu werden.

      
Mehrere Buchstaben sind neu gezeichnet. Das a wird einstöckig, das f reicht unter die Grundlinie und schwingt zurück, und die Stämme von a d i h m n u laufen in kleine Auslaufstriche aus. Der Ballast funktioniert weiter: In der Kursiven sammelt sich die Masse in diesen Ausläufen.

Text in Ruhe

    

      
Eine vielseitige Textschrift hat zwei Aufgaben. In der Überschrift muss sie hervortreten, im Absatz zurücktreten. In Ruhe ist Senklot eine ruhige, offene Groteske mit großzügiger x-Höhe, weiten Öffnungen und gerade abgeschnittenen Strichenden, die auf dem Raster einrasten.

      
Ihr Charakter ist ein leichter Zug nach unten: Querstriche sitzen tief, und Stämme werden zur Grundlinie hin etwas kräftiger. Sie ist geerdet, ohne schwer zu sein, und die Kursive behält dieses ruhige Gewicht. Erst wenn du die Masse bewegst, zeigt sich das System.

      
Größe, Übermut und Äpfel: Die Umlaute tragen ihren eigenen Ballast. Die Ziffern 0123456789 stehen im selben Lot.

Bei gleichem Schriftgewicht bleiben die Zeichenbreiten entlang beider Ballast-Achsen konstant. Dadurch bleiben die Zeilenumbrüche beim Animieren erhalten. Wenn sich das Gewicht ändert, ändern sich auch die Breiten.

  


  

    
Auf deiner Website einbinden

    
    
      
  1. Dateien kopieren
    Entpacke den Download und kopiere den Inhalt von web/ in einen Ordner deiner Website, zum Beispiel /fonts/. Der Ordner enthält fünf Dateien: senklot.css, die beiden variablen .woff2-Dateien, OFL.txt (Lizenz der Schriften) und LICENSE-CODE.txt (Lizenz des Stylesheets). Lass alle fünf zusammen.
    2. 
      
  2. Stylesheet einbinden
    
        
    <link rel="preload" href="/fonts/Senklot[wght,BLSY,BLSX].woff2" as="font" type="font/woff2" crossorigin>
<link rel="stylesheet" href="/fonts/senklot.css">
    3. 
      
  3. Wie jede Schrift verwenden
    
        
    body   { font-family: "Senklot", system-ui, sans-serif; }
strong { font-weight: 700; }
em     { font-style: italic; }        /* wählt die echte Kursive */
h1     { font-weight: 600; }
    4. 
      
  4. Den Ballast bewegen
    
        
    Gewicht und Kursive funktionieren mit normalem CSS. Die Ballast-Achsen laufen über font-variation-settings. Diese Eigenschaft wird immer als Ganzes ersetzt, setze also beide Achsen zusammen. Mit Custom Properties geht das einfach:
    
        
    h1 {
  font-variation-settings: "BLSY" var(--blsy, 0), "BLSX" var(--blsx, 0);
  transition: font-variation-settings .6s cubic-bezier(.3, 1.6, .5, 1);
}
h1:hover { --blsy: 100; }

/* Rücksicht auf alle, die Bewegung abschalten */
@media (prefers-reduced-motion: reduce) {
  h1 { transition: none; }
}
    5. 
      
  5. Mit JavaScript animieren
    
        
    Das steuert die Custom Properties aus Schritt 4. So behält das CSS dort die Kontrolle, und reduzierte Bewegung wird respektiert.
    
        
    const el = document.querySelector("h1");
const reduced = matchMedia("(prefers-reduced-motion: reduce)").matches;

if (!reduced) {
  addEventListener("pointermove", e => {
    const y = (e.clientY / innerHeight * 2 - 1) * 100;
    const x = (e.clientX / innerWidth  * 2 - 1) * 100;
    el.style.setProperty("--blsy", y.toFixed(1));
    el.style.setProperty("--blsx", x.toFixed(1));
  }, { passive: true });
}
    6. 
    

    
Browser-Unterstützung: Variable Fonts mit eigenen Achsen funktionieren in allen aktuellen Versionen von Chrome, Edge, Safari und Firefox. Für ältere Browser oder Umgebungen ohne Variable Fonts bieten die statischen Dateien in web/static/ sechs feste Gewichte pro Stil, ohne Ballast-Achsen.

Wie sie entsteht

    

      

        
Jedes Zeichen ist ein Skelett aus Geraden und Superellipsen-Bögen. Die Kontur entsteht, indem jeder Punkt dieses Skeletts um eine halbe Strichbreite aus dem Feld versetzt wird:

        
halbe Breite = Basis × Kontrast × (1 + 0.10·v + 0.55·BLSY·v + 0.40·BLSX·u)

        
Kontrast macht waagerechte Striche etwa 12 % leichter als senkrechte, wie bei den meisten Grotesken. Der Rest ist das Feld: u ist die waagerechte Position ab der Buchstabenmitte (−1 links bis +1 rechts) und v die Höhe, von +1 an der Unterlänge bis etwa −0,7 an der Oberlänge. BLSY und BLSX sind die Achsenwerte geteilt durch 100, also −1 bis +1. Weil jeder Konturpunkt linear von dieser halben Breite abhängt, sind die Master von vornherein kompatibel. Beim Schreiben der Schriftdateien werden die Koordinaten auf ganze Einheiten gerundet.

      

      
    
        
  • 15 Master pro Stil, inklusive Ecken für Gewicht × Ballast, damit Kombinationen keine zusätzliche Korrektur brauchen.
    • 
        
  • Mit steigendem Gewicht werden runde Kanten nach innen gezogen, damit Überhänge auf den Hilfslinien bleiben.
    • 
        
  • Die Kursive neigt das Skelett um 9°, bevor die Striche entstehen, damit sie ihre senkrechte Dicke behalten.
    • 
        
  • Klassen-Kerning für die üblichen Paare, auch für Buchstaben mit Akzent.
    • 
        
  • Alle Dateien bestehen den OpenType Sanitizer, die Prüfung, die Browser bei Webfonts durchführen.

Lizenz, Herkunft, Grenzen

    

      

        
Herkunft

        
Die Schriftkonturen entstehen aus den in src/glyphs.py definierten Buchstabenskeletten. Der Build verwendet keine bestehende Schriftdatei als Vorlage.
