Senklot

A sans-serif with a movable centre of mass. Stroke weight depends on where the ink sits, not on which way the stroke runs. Move the weight, and every letter feels it.

The idea

In every typeface so far, stroke thickness follows direction: heavy verticals, light horizontals, perhaps flipped for a western poster. Senklot ignores direction. Its thickness is a field laid over each letter, and that field has a centre of gravity.

Two axes move that centre. BLSY sinks or lifts the mass. BLSX drifts it sideways. The skeleton never changes, so text never reflows. Only the ink moves.

The dots on i and j, in punctuation and on umlauts are loose ballast. They swell, shrink and drift toward the mass.

The axes combine freely. Bold Italic with the mass sunk to the left is as exact as Regular at rest, because all fifteen masters are interpolated without approximation.

The italic

    

      
Senklot Italic is a true italic, not a slanted roman. The skeleton is slanted by 9° before the strokes are drawn, so every stroke keeps its real thickness instead of being squashed.

      
Several letters are redrawn. The a becomes single-storey, f drops below the baseline and hooks back, and the stems of a d i h m n u roll out into small exit strokes. The ballast still works: in italic, the mass gathers in those exits.

Text at rest

    

      
A good typeface for a personal site has to do two jobs. It must step forward in a headline and step back in a paragraph. At rest, Senklot is a calm, open sans with a generous x-height, wide apertures and squared terminals that snap to the grid.

      
Its personality is a slight downward pull: crossbars sit low and stems swell a touch toward the baseline. It is grounded without being heavy, and the italic keeps that same quiet weight. Only when you move the mass does the system reveal itself.

      
Größe, Übermut und Äpfel: the umlauts carry their own ballast. The figures 0123456789 stand on the same plumb line.

Use it on your site

    
    
      
  1. Copy the files
    Unzip the download and copy the contents of web/ into a folder on your site, for example /fonts/. You need senklot.css and the two variable .woff2 files.
    2. 
      
  2. Link the stylesheet
    
        
    <link rel="preload" href="/fonts/Senklot[wght,BLSY,BLSX].woff2" as="font" type="font/woff2" crossorigin>
<link rel="stylesheet" href="/fonts/senklot.css">
    3. 
      
  3. Use it like any font
    
        
    body   { font-family: "Senklot", system-ui, sans-serif; }
strong { font-weight: 700; }
em     { font-style: italic; }        /* picks the true italic */
h1     { font-weight: 600; }
    4. 
      
  4. Move the ballast
    
        
    Weight and italic use normal CSS. The ballast axes go through font-variation-settings. That property replaces itself as a whole, so always set both axes together. Custom properties make that easy:
    
        
    h1 {
  font-variation-settings: "BLSY" var(--blsy, 0), "BLSX" var(--blsx, 0);
  transition: font-variation-settings .6s cubic-bezier(.3, 1.6, .5, 1);
}
h1:hover { --blsy: 100; }

/* respect people who turn motion off */
@media (prefers-reduced-motion: reduce) {
  h1 { transition: none; }
}
    5. 
      
  5. Animate from JavaScript
    
        
    const el = document.querySelector("h1");
addEventListener("pointermove", e => {
  const y = (e.clientY / innerHeight * 2 - 1) * 100;
  const x = (e.clientX / innerWidth  * 2 - 1) * 100;
  el.style.fontVariationSettings = `"BLSY" ${y}, "BLSX" ${x}`;
});
    6. 
    

    
Browser support: variable fonts with custom axes work in all current versions of Chrome, Edge, Safari and Firefox. For very old browsers, the static files in web/static/ give six fixed weights per style without the ballast axes.

How it is made

    

      

        
Every glyph is a skeleton of straight lines and superellipse arcs. The outline is drawn by offsetting each point of that skeleton by a half-width taken from the field:

        
half-width = base × contrast × (1 + 0.10·v + 0.55·BLSY·v + 0.40·BLSX·u)

        
Here v is the height in the letter and u the horizontal position. Because every outline point depends linearly on that half-width, the font interpolates exactly between its masters.

      

      
    
        
  • 15 masters per style, including corners for weight × ballast, so combinations stay exact.
    • 
        
  • As weight increases, round edges are pulled inward so overshoots stay on the guidelines.
    • 
        
  • The italic shears the skeleton by 9° before stroking, so strokes keep their perpendicular thickness.
    • 
        
  • Class kerning for the usual pairs, including the accented letters.
    • 
        
  • All files pass the OpenType Sanitizer, the check browsers run on web fonts.

Licence, provenance, limits

    

      

        
Provenance

        
Senklot was generated from original parametric skeletons written for this project. No outlines, metrics or data from any existing font were used, traced or derived.

        
Licence

        
Senklot is free and open under the SIL Open Font License 1.1. Use it on websites, in apps, print and commercial work, embed it, modify it and share it. The only rules: don't sell the fonts on their own, and keep modified versions under the OFL. Full licence text.

      

      

        
Known limits

        
    
          
  • No TrueType hinting, so small sizes on Windows look slightly softer. macOS, iOS and Android are unaffected.
    • 
          
  • No small caps, ligatures or alternate figures yet.
    • 
          
  • Western European Latin only. Polish, Czech and other Central European letters are missing.
